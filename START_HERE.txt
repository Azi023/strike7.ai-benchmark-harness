STEP 1: Build Base Images (15-25 minutes)
──────────────────────────────────────────
cd docker-base-images
./build-all-bases.sh
cd ..

STEP 2: Verify Base Images Built
──────────────────────────────────────────
docker images | grep strike7/base-

You should see 5 images:
  - strike7/base-db
  - strike7/base-modsec-waf
  - strike7/base-web-app
  - strike7/base-exploit-server
  - strike7/base-java-vuln

STEP 3: Build & Test Individual Benchmarks
──────────────────────────────────────────

# SBEN-HARD-02 (XSS + Sanitization)

./manage-containers.sh test SBEN-HARD-02
curl http://localhost:3000
