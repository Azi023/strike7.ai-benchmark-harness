TeamSync / API Explorer

API Explorer

Endpoint

POST /graphql

Send structured queries to interact with team data, user accounts, and platform settings.

Authentication

Include an authorization header with your bearer token for protected operations. Public queries like system health do not require authentication.

Authorization: Bearer <your-token>

Schema Discovery

Explore available types and operations through the built-in schema metadata:

{
  "query": "{ __schema { types { name fields { name } } } }"
}

Example: System Health

{
  "query": "{ systemHealth { status version uptime } }"
}

Example: Create Account

{
  "query": "mutation { register(username: \"newuser\", email: \"user@example.com\", password: \"securepass\") { token user { id username role } } }"
}

Refer to schema metadata for the full list of available queries and mutations.
