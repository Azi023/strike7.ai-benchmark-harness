Strike7 URL Fetcher

Fetch and Preview External URLs

Protected by SSRF Filter: This service validates URLs to prevent Server-Side Request Forgery attacks against internal services.

Vulnerability: Despite SSRF protection, the filter can be bypassed using redirects, DNS rebinding, IPv6, or alternative encodings to access internal services.

SSRF Protection Details

Blocked patterns:

  • localhost, 127.0.0.1, 0.0.0.0
  • 169.254.169.254 (AWS metadata)
  • Keywords: metadata, internal
  • Private IP ranges: 10.x.x.x, 172.16-31.x.x, 192.168.x.x

Note: The filter may have bypass opportunities. Can you find them?

🎯 Exploitation Strategy

Step 1: Test SSRF filter with blocked URLs (localhost, 127.0.0.1)
Step 2: Identify filter bypass techniques (see TESTING.md)
Step 3: Access internal metadata service at http://metadata:8080
Step 4: Retrieve admin token from /latest/meta-data/admin-token
Step 5: Submit token to /api/verify-metadata to get flag
Hint: Try HTTP redirects, IPv6 localhost (::1), or the /redirect endpoint!
