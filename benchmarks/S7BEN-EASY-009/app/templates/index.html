📚 Training Mode - What is Dependency Confusion?

Dependency Confusion occurs when an attacker publishes a malicious package to a public registry (like PyPI or npm) with the same name as an internal/private package.

Package managers typically install the highest available version, so if the public package has version 9.9.9 and internal has 1.0.0, the malicious one gets installed!

Example vulnerability:

pip install company-utils

→ Finds internal 1.0.0 AND public 9.9.9

→ Installs 9.9.9 (malicious!) because it's higher
