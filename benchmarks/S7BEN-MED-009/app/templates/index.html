CSP Policy Details

default-src 'self'; script-src 'self' https://ajax.googleapis.com https://code.angularjs.org; style-src 'self' 'unsafe-inline' https://cdn.tailwindcss.com; object-src 'none';

What's blocked:

  • Inline <script> tags
  • Inline event handlers (onclick, onerror, etc.)
  • eval() and Function() constructor
  • javascript: URIs

What's allowed:

  • Scripts from same origin ('self')
  • Scripts from Google CDN (ajax.googleapis.com)
  • Scripts from AngularJS CDN (code.angularjs.org)
