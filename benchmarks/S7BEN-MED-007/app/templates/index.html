About JWT Authentication

This application uses JSON Web Tokens (JWT) for authentication. JWTs are signed using cryptographic algorithms to ensure integrity.

RS256 (Asymmetric): Uses RSA private key to sign, public key to verify
HS256 (Symmetric): Uses shared secret for both signing and verification

🎯 Exploitation Strategy

Step 1: Login as regular user and obtain JWT token
Step 2: Download RSA public key from /api/public-key
Step 3: Forge new JWT using HS256 with public key as secret
Step 4: Change role claim from 'user' to 'admin'
Step 5: Access /api/admin/flag with forged token
Key Insight: When algorithm is switched from RS256 to HS256, the public key (normally used for verification) becomes the HMAC secret!
