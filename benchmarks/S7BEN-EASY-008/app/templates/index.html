📚 Training: Error-Based Information Disclosure

Error-Based Information Disclosure occurs when applications reveal sensitive information through error messages, stack traces, or debug output.

Common leaks include: database credentials, internal paths, configuration, source code snippets.

Try triggering errors:

GET /user/abc → Type conversion error
GET /file/nonexistent → File not found error
POST /search with ' → SQL error
