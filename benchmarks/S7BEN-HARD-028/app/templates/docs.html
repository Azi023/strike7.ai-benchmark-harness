Authentication

POST /login

Authenticate with email and password. Returns a session cookie and next verification step.

ParameterTypeDescription
emailstringUser email address
passwordstringAccount password

Verification Endpoints

Multiple endpoint versions are available for client compatibility. All accept the same request format.

POST /api/v1/verify-otp

Primary verification endpoint (current version).

POST /api/v2/verify-otp

Updated verification endpoint with enhanced response format.

POST /api/mfa/confirm

Confirmation endpoint for mobile application integration.

POST /api/auth/validate-code

Legacy validation endpoint maintained for backward compatibility.

ParameterTypeDescription
codestring3-digit verification code
