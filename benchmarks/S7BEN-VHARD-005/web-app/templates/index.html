Available Endpoints

GET /health

Health check endpoint

POST /api/login

Login and receive pickled session cookie

{"username": "user", "password": "pass"}
GET /api/profile

View profile (deserializes session cookie) 🔴 VULNERABLE

POST /api/cache/set

Store data in Redis cache (pickled) 🔴 VULNERABLE

{"key": "mykey", "value": "myvalue", "ttl": 3600}
GET /api/cache/get/<key>

Retrieve cached data (deserializes pickle) 🔴 VULNERABLE

POST /api/task/submit

Submit Celery task to worker queue 🔴 VULNERABLE

{"task_name": "process_data", "args": ["arg1", "arg2"]}
GET /api/session/example

Get example pickled session structure

GET /api/flag

Flag location hint

GET /api/debug/redis

List Redis cache keys (reconnaissance)

Vulnerabilities

  • CUSTOM-PICKLE-01: Session cookies use insecure pickle deserialization
  • CUSTOM-PICKLE-02: Redis cache stores untrusted pickled objects
  • CUSTOM-PICKLE-03: Celery worker deserializes task payloads

Flags

  • /app/flag.txt - Web application flag
  • /data/cache_flag.txt - Redis cache flag
  • /worker/secret_flag.txt - Celery worker flag
