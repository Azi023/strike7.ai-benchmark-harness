🚀 RUNNING TESTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANT: Always activate venv first!
  cd ~/workspace/strike7-benchmarks
  source venv/bin/activate

Start dashboard (in another terminal):
  cd ~/workspace/strike7-benchmarks/dashboard
  source ../venv/bin/activate
  python app.py

Quick test (4 tests):
  cd dashboard/tests
  ./quick_test.sh

Full suite (27 tests):
  cd dashboard/tests
  ./run_tests.sh

Specific test:
  pytest test_e2e_playwright.py::TestSearchFunctionality -v


🔧 COMMON ISSUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "No module named pytest"
   → source venv/bin/activate
   → pip install pytest pytest-playwright

❌ "Executable doesn't exist at .../chromium..."
   → playwright install chromium

❌ "Permission denied"
   → chmod +x *.sh

❌ "Connection refused to localhost:5500"
   → Start dashboard: cd dashboard && python app.py
